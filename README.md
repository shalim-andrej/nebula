# NEBULA® — концепт-сайт digital-агентства

Премиальный одностраничник вымышленного digital-агентства NEBULA®: сайты, приложения, брендинг. Агентство само себе витрина — здесь это решено через showreel и бриф-форму, которая квалифицирует лид по бюджету.

**Демо:** [shalim-andrej.github.io/nebula](https://shalim-andrej.github.io/nebula/)

## Визуальный язык

- Видео-обложка с шоуриллом SHOWREEL 2026 (1:24) вместо статичного hero
- Контрастная типографика со смешанной вёрсткой RU/EN заголовков
- Кейсы и услуги как элементы единой композиции
- Мягкие blur-слои и глубокий фон

Каждый проект в премиум-пятёрке имеет собственную сетку и палитру — NEBULA® отвечает в связке за «технологичность и смелость».

## Структура страницы

| Блок | Содержание |
|---|---|
| Первый экран | шоурилл, айдентика агентства |
| Услуги | сайты, приложения, брендинг |
| Кейсы | проекты и результаты |
| Процесс | этапы работы над проектом |
| Студия | команда и подход |
| Контакты | бриф-форма: имя, контакт, бюджет, описание задачи |

## Что внутри технически

- **Два HTML5-видео**: showreel в первом экране и фоновые вставки
- **Glassmorphism** — панели и карточки на `backdrop-filter`
- **Параллакс** — слои, привязанные к скроллу
- **Reveal-анимации** на IntersectionObserver + кастомные `@keyframes`
- **CSS Grid** и кастомные свойства, fluid-типографика на `clamp()`
- **Адаптив** всех блоков, `loading="lazy"` для изображений
- **Open Graph** разметка и `meta description`
- **Ноль зависимостей** — vanilla JS, стили и скрипты написаны с нуля

## Запуск локально

```bash
git clone https://github.com/shalim-andrej/nebula.git
cd nebula
```

Откройте `index.html` в браузере — сборка и зависимости не нужны.
